# Radio sensor based social sensing as phenotypical marker in psychotic patients 

## Objective:
Embedd radio signals (frequency: 4s over 3 months) into social interaction graphs and ivestigate statistical relationshsip to symptom severity (PANSS)

## Hierarchy of actions: 
1. preprocessing_sensors.py
2. analysis_sensor_network_measures.py & analysis_survey_sensor_associations.py - Extract graph based topological markers and PANSS metrics
3. panss_rssi.py - Predict PANSS metrics with topological markers
4. analysis_figures.py & analysis_video.py - Visualize results
